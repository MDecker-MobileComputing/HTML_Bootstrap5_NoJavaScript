Glossary with Bootstrap 5 Accordion

The following glossary with expandable entries was created using the Bootstrap 5 accordion component. By clicking an item, it can be expanded while another open item may be collapsed.

Cascading Style Sheets. A declarative programming language used to define the appearance of an HTML page.

Hypertext Markup Language. A markup language used to define the structure and actual content (especially text) of a web page.

Hypertext Transfer Protocol. A stateless application-layer protocol used, among other things, to transfer files from a website's server to the browser.

Programming language. JavaScript can be embedded in a web page to run code directly in the browser.

Uniform Resource Identifier. A string used to uniquely identify a resource; URLs are a special case of URIs.

Uniform Resource Locator. A special case of a URI that also contains information about where to obtain the resource. URLs are what is usually entered in a browser's address bar to open a specific website.

Collection of web pages. A website consists of one or more web pages (HTML documents) and can be accessed under a specific URL (often a domain).
